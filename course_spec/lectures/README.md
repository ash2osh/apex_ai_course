# Oracle APEX AI + Workflow — Masterclass Lecture Packages

Welcome to the **Oracle APEX AI + Workflow** specification-first curriculum. Every episode contains:
1. **`lecture_notes.md`**: Complete lesson plan, timed talking points, live demo steps, and FAQs.
2. **`prompts.md`**: Ready-to-copy Coding Agent prompts and live chat interaction prompts.
3. **Optional demonstration code (`.sql` / `.sh`)**: A teaching example when the episode benefits from one. Examples assume the target implementation has first been generated inside the initialized template repository.
4. **`slides.pptx`**: Full 16:9 widescreen PowerPoint presentation.
